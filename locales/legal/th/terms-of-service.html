ข้อกำหนดและเงื่อนไขการใช้งานสำหรับ [Nama Server Anda]

 

วันที่มีผลบังคับใช้: 26 มิถุนายน 2025

 

1. การยอมรับข้อกำหนด

 

การสร้างบัญชีและ/หรือการใช้บริการเซิร์ฟเวอร์เกมของ [Nama Server Anda] (“บริการ”) ถือว่าคุณยอมรับที่จะผูกพันตามข้อกำหนดและเงื่อนไข (“ข้อกำหนด”) เหล่านี้ หากคุณไม่เห็นด้วยกับส่วนใดส่วนหนึ่งของข้อกำหนดเหล่านี้ คุณจะไม่ได้รับอนุญาตให้ใช้บริการ

 

2. คำอธิบายบริการ

 

[Nama Server Anda] เป็นเซิร์ฟเวอร์เกมส่วนตัว (private server) ที่บริหารจัดการโดยชุมชนเพื่อวัตถุประสงค์ด้านความบันเทิง บริการนี้ไม่มีส่วนเกี่ยวข้อง รับรอง หรือเชื่อมต่อกับ ESTgames หรือผู้จัดจำหน่าย Cabal Online อย่างเป็นทางการอื่นๆ เครื่องหมายการค้าทั้งหมดเป็นทรัพย์สินของเจ้าของที่เกี่ยวข้อง

   

3. บัญชีผู้ใช้

 
         
  • คุณมีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในการรักษาความลับของข้อมูลบัญชีของคุณ รวมถึงรหัสผ่าน
    •      
  • คุณต้องรับผิดชอบต่อกิจกรรมทั้งหมดที่เกิดขึ้นภายใต้บัญชีของคุณ
    •      
  • เราขอสงวนสิทธิ์ในการระงับ (suspend) หรือยุติ (terminate) บัญชีของคุณได้ตลอดเวลา โดยมีหรือไม่มีการแจ้งเตือน ในกรณีที่มีการละเมิดข้อกำหนดเหล่านี้
    •  
   

4. หลักปฏิบัติ (Code of Conduct)

 

เมื่อใช้บริการของเรา คุณตกลงที่จะไม่:

 
         
  • ใช้โปรแกรมโกง, แฮ็ก, บอท, สคริปต์ หรือซอฟต์แวร์บุคคลที่สามที่ไม่ได้รับอนุญาตเพื่อแก้ไขประสบการณ์การเล่นเกม
    •      
  • ใช้ประโยชน์จากข้อบกพร่อง (bug) หรือความผิดพลาด (glitch) ในเกมเพื่อประโยชน์ส่วนตัว
    •      
  • คุกคาม, ข่มขู่, รังแก หรือเผยแพร่คำพูดที่สร้างความเกลียดชังต่อผู้เล่นหรือเจ้าหน้าที่คนอื่นๆ
    •      
  • แอบอ้างเป็นเจ้าหน้าที่หรือตัวแทนของ [Nama Server Anda]
    •      
  • มีส่วนร่วมในการซื้อขายด้วยเงินจริง (Real Money Trading - RMT) รวมถึงการขาย/ซื้อไอเทม, Alz หรือบัญชีด้วยสกุลเงินจริง
    •      
  • รบกวนหรือพยายามรบกวนการทำงานของเซิร์ฟเวอร์
    •  
 

การละเมิดหลักปฏิบัตินี้อาจส่งผลให้เกิดการลงโทษตั้งแต่การเตือน, การระงับชั่วคราว, ไปจนถึงการบล็อกบัญชีและ/หรือที่อยู่ IP อย่างถาวร

 

5. การบริจาค

 
         
  • ธุรกรรมทางการเงินทั้งหมดที่ทำกับ [Nama Server Anda] ถือเป็น **การบริจาคโดยสมัครใจ** เพื่อสนับสนุนค่าใช้จ่ายในการดำเนินงานและการบำรุงรักษาเซิร์ฟเวอร์
    •      
  • เพื่อเป็นการขอบคุณ ผู้บริจาคจะได้รับไอเทมเสมือนในเกม (เช่น "eCoins") ตามแพ็กเกจที่ระบุไว้
    •      
  • การบริจาคทั้งหมดถือเป็นที่สิ้นสุดและ **ไม่สามารถขอคืนเงินได้ (NO REFUNDS)** ไม่ว่าในกรณีใดๆ
    •      
  • การโต้แย้งหรือ "chargeback" สำหรับการบริจาคที่สำเร็จแล้วจะส่งผลให้บัญชีที่เกี่ยวข้องทั้งหมดถูกบล็อกอย่างถาวร
    •  
 

6. การยุติบริการ

 

เราขอสงวนสิทธิ์ในการแก้ไข ระงับ หรือยุติบริการ (หรือส่วนใดส่วนหนึ่งของบริการ) ได้ตลอดเวลา โดยมีหรือไม่มีเหตุผล เราจะไม่รับผิดชอบต่อคุณหรือบุคคลที่สามใดๆ สำหรับการแก้ไข การระงับ หรือการยุติบริการ

 

7. ข้อจำกัดความรับผิดชอบในการรับประกัน

 

บริการนี้ให้บริการ "ตามสภาพ" และ "ตามที่มี" โดยไม่มีการรับประกันใดๆ ทั้งโดยชัดแจ้งหรือโดยนัย เราไม่รับประกันว่าบริการจะไม่มีการหยุดชะงัก ข้อผิดพลาด หรือข้อบกพร่อง
