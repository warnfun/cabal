นโยบายความเป็นส่วนตัวสำหรับ [Nama Server Anda]

 

วันที่มีผลบังคับใช้: 26 มิถุนายน 2025

 

1. บทนำ

 

ยินดีต้อนรับสู่ [Nama Server Anda] เราให้ความสำคัญกับความเป็นส่วนตัวของคุณและมุ่งมั่นที่จะปกป้องข้อมูลดังกล่าว นโยบายความเป็นส่วนตัวนี้อธิบายประเภทของข้อมูลที่เราเก็บรวบรวมจากคุณ หรือที่คุณให้ไว้เมื่อคุณเยี่ยมชมเว็บไซต์และใช้บริการเกมของเรา รวมถึงวิธีที่เราใช้ ปกป้อง และเปิดเผยข้อมูลดังกล่าว

 

2. ข้อมูลที่เรารวบรวม

 

เราเก็บรวบรวมข้อมูลหลายประเภท รวมถึง:

 
       
  • ข้อมูลที่คุณให้โดยตรง:        
                 
    • เมื่อคุณลงทะเบียน เราจะเก็บรวบรวม User ID, รหัสผ่าน (ซึ่งเราจัดเก็บในรูปแบบแฮช) และที่อยู่อีเมลของคุณ
      •            
    • เมื่อคุณติดต่อเราเพื่อขอรับการสนับสนุน เราจะจัดเก็บประวัติการติดต่อ
      •        
       
    •    
  • ข้อมูลที่รวบรวมโดยอัตโนมัติ:        
                 
    • ข้อมูลเกม: เราจัดเก็บข้อมูลความคืบหน้าทั้งหมดของคุณในเกม เช่น ตัวละคร, เลเวล, ไอเทม, กิลด์, Alz และกิจกรรมอื่นๆ
      •            
    • ข้อมูลการเข้าสู่ระบบและการเข้าถึง: เราอาจบันทึกที่อยู่ IP, ประเภทเบราว์เซอร์ และเวลาการเข้าถึงของคุณเพื่อวัตถุประสงค์ด้านความปลอดภัยและการวิเคราะห์
      •        
       
    •    
  • ข้อมูลการบริจาค:        
                 
    • เมื่อคุณทำการบริจาค เราจะบันทึก ID ธุรกรรม, แพ็กเกจที่เลือก และจำนวนเงินบริจาคเพื่อดำเนินการมอบไอเทมเสมือน (eCoins)
      •            
    • เราไม่เคยจัดเก็บข้อมูลทางการเงินที่ละเอียดอ่อน เช่น หมายเลขบัตรเครดิต, รายละเอียดบัญชีธนาคาร หรือรหัสผ่าน PayPal ของคุณ กระบวนการนี้ได้รับการจัดการโดยสมบูรณ์จากผู้ให้บริการชำระเงินบุคคลที่สามที่ปลอดภัย (เช่น PayPal, Tripay)
      •        
       
    •      
  • ข้อมูลจากบุคคลที่สาม:        
                 
    • หากคุณเลือกที่จะเชื่อมโยงบัญชี Discord ของคุณ เราจะได้รับข้อมูลพื้นฐานจาก Discord เช่น ID และชื่อผู้ใช้ของคุณ เพื่อวัตถุประสงค์ในการรวมระบบ เช่น การส่ง OTP (One-Time Password)
      •        
       
    •  
 

3. เราใช้ข้อมูลของคุณอย่างไร

 

เราใช้ข้อมูลที่เราเก็บรวบรวมเพื่อ:

 
       
  • ให้บริการ บำรุงรักษา และปรับปรุงบริการเกมของเรา
    •    
  • จัดการบัญชีของคุณและดำเนินการบริจาคของคุณ
    •    
  • ส่งการแจ้งเตือนที่สำคัญเกี่ยวกับบัญชีหรือบริการ เช่น การรีเซ็ตรหัสผ่านหรือการส่งรหัส OTP
    •    
  • เพิ่มความปลอดภัยและป้องกันการฉ้อโกงหรือการใช้งานในทางที่ผิด
    •    
  • สื่อสารกับคุณเกี่ยวกับคำถามหรือคำขอการสนับสนุน
    •    
  • ให้แน่ใจว่าปฏิบัติตามข้อกำหนดและเงื่อนไขของเรา
    •  
 

4. ความปลอดภัยของข้อมูล

 

เราใช้มาตรการรักษาความปลอดภัยที่สมเหตุสมผลเพื่อปกป้องข้อมูลส่วนบุคคลของคุณจากการเข้าถึง การใช้งาน หรือการเปิดเผยที่ไม่ได้รับอนุญาต รหัสผ่านของคุณถูกจัดเก็บโดยใช้เทคโนโลยีการแฮชที่แข็งแกร่ง

   

5. ความเป็นส่วนตัวของเด็ก

 

บริการของเราไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี เราไม่ได้เจตนาเก็บรวบรวมข้อมูลส่วนบุคคลจากเด็กอายุต่ำกว่า 13 ปี หากคุณเป็นพ่อแม่หรือผู้ปกครองและคุณทราบว่าบุตรหลานของคุณได้ให้ข้อมูลส่วนบุคคลแก่เรา โปรดติดต่อเรา

 

6. การเปลี่ยนแปลงนโยบายความเป็นส่วนตัวนี้

 

เราอาจอัปเดตนโยบายความเป็นส่วนตัวของเราเป็นครั้งคราว เราจะแจ้งให้คุณทราบเกี่ยวกับการเปลี่ยนแปลงใดๆ โดยการโพสต์นโยบายใหม่ในหน้านี้ ขอแนะนำให้คุณตรวจสอบนโยบายความเป็นส่วนตัวนี้เป็นระยะ
